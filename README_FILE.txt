Folder Structure for Assignment Outputs

The following folder structure is used to store the training outputs generated during execution of the notebook.

MyDrive/
│
├── DL_Prog2/
│   │
│   ├── checkpoints/

│   │   └── last.keras
│   │
│   ├── logs/
│   │   └── history.csv
│   │
│   └── runs/
│       ├── class_names.json
│       ├── config.json
│       └── model_summary.txt


checkpoints/
 - best.keras – Model checkpoint with the best validation accuracy
 - last.keras – Most recent model checkpoint during training

logs/
 - history.csv – Training history containing loss and accuracy for each epoch

runs/
 - class_names.json – Mapping of class labels used in the dataset
 - config.json – Configuration parameters used for training
 - model_summary.txt – Summary of the CNN architecture
